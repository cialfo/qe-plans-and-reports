New Surfaces
CDocs — Documents (Common App Forms — Mid Year Report) — Two new questions on the Mid Year Report's summary section, shown only when "Do you want to provide an updated evaluation for this applicant?" = Yes: Q3001 a checkbox group ("Upload a document" / "Write a response", multi-select) and Q3002 a conditional free-text response (1–250 words, required only when "Write a response" is checked). Selecting "Upload a document" continues to show the existing file-upload control; selecting neither leaves both hidden. No prior TC module exists for the cdocs-common-app-forms feature area (Mid Year Report, School Report, Optional Report, Optional Report 2, Final Report, Counselor Profile, Early Decision Agreement forms) — this PR is the first change QE has evaluated in it.
CDocs — Documents (Common App Forms — date-picker bounds) — Class-rank / GPA date question bounds widened by one year on both ends (min 1955→1956, max 2030→2031) across Counselor Profile, School Report, MidYear Report, Optional Report, Optional Report 2, and Final Report. Separately, other date questions (Counselor Profile Q1969, Early Decision Agreement Q1501/Q1732) had their bounds increased to 2026–2027 per the PR description, though no corresponding source change for those specific questions appears in this diff — see flag below.
CDocs — Documents (School Information — Mid Year Report date window) — The School Information Mid Year Report section's date-range validator (`withinCurrentYearValidator` → renamed `withinAllowedDateRangeValidator`) changed from a single-cycle rolling window (Aug cutoff, current/current+1 year) to a fixed 13-year window: currentYear−10 to currentYear+2. A next-cycle mid-year date (year+1) that the old validator wrongly rejected now passes.
