  1. Open the student's cDocs section.
  2. Locate a document ready to send to Common App.
  3. Click the send action for that document.
  4. Confirm the send in any confirmation dialog.
 The send fails and the error message reads: 'Common App blocked this send because the student's FERPA release is incomplete. They need to finish the FERPA step under Recommenders and FERPA in Common App. Then send again. If it's already complete, contact Cialfo support.' The old text ('Please make sure that student has waived off the FERPA…') does not appear. A student account where Common App returns error code 1. Because triggering this against live Common App is noted as unverified in the PR, a test environment with a stubbed or replayed Common App response returning code 1 is acceptable.
