The banner's helper-pill and 'Ask Saige' click handlers call openAiService.openSaige() with no surface option, so they now navigate to /saige with a minted chat instead of opening the drawer overlay — the existing TCs assert drawer behaviour.

New Surfaces
Dashboards & Reports — Student Dashboard / Counselor Dashboard (top nav) — The Saige entry points (top-nav mascot, dashboard banner, helper pills) now open a full-screen dedicated chat surface at /saige by default instead of the 50%-width drawer. This is new behaviour layered on top of PR #4819's still-unmerged /saige route — this PR (#4826) adds the actual exit paths (topbar 'X', rail 'Back to Cialfo' footer), a 'collapse to sidebar' action that hands the open chat back to the drawer, and a 'switch blocked while replying' guard on both the drawer's expand button and the full screen's collapse button.
Apps — Direct Apply (personal-statement review) — Personal-statement review now always starts on a brand-new chat (openSaige is called with a hook that forces SaigeChatsService.startNewChat()), rather than possibly continuing whatever chat was most recently active. Same rule was added to the drawer sidebar's own chat-resolution logic.
N/A — chat surface UI (component-level, not yet an existing TC module) — Suggestion chips in the chat transcript now collapse to 2 visible chips at rest with a '+N more' / 'Show fewer' toggle pill, instead of always showing every suggestion. Applies to both the drawer and the full screen since both render app-saige-chat.
