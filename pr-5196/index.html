New Surfaces
Apps — Applications — Full rebuild of the student Applications page as 'applications-v7' — reachable via a canMatch guard (applicationsOnNewVersion) that defaults every student to the new screen on staging (routes are only withheld from a true production build). Encompasses: the page shell (screen-preview) with volume-based chrome thresholds and a load-error state distinct from zero-state; a summary strip; a 4-axis split control (all/attention/step/portal); a grouped section list of application cards and UCAS/UK-DA bundles; a card kebab menu that merges a designed action set with backend-supplied actions; a detail drawer with conditional sections including a private, save-on-blur student note; a right panel with UCAS/Common App/Direct-Apply-inbox portal cards (each with its own state machine) plus a 'More views' area (logins/transcripts/letters/report); a curated nav panel; a zero-state with an add-slot and profile-matched suggestions; per-stage empty states; a scroll- or timer-triggered feedback prompt; and a full beta switch-back flow (ask-why → detail → switch, a 3-strikes-then-pinned rule, a return pill on the old screen, and a one-time 'welcome back' bar) that lets a student move between the new and previous screens for the duration this beta period runs.
